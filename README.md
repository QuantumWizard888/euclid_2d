# Euclid 2D

## ⚛️ Simple particles simulation sandbox

Small particles simulation sandbox with physics. Created using Pygame.

[Demonstration video #1](https://files.catbox.moe/vy2qcs.mp4)

[Demonstration video #2](https://files.catbox.moe/5zxw5e.mp4)

[Force field demo video #3](https://files.catbox.moe/nx7u9p.mp4)

### ⭐ Feautures
* Multiple particles creation with collision physics
* Gravity mode
* Force field mode for particles (with an option to increase/decrease Force field radius and Force value)
* Zero field mode for particles (it makes particles freeze)
* Thermal velocity mode where particle colour depends on its velocity
* Push other particles with manual single particle control
* Pause simulation
* Create simulation screen screenshot
* Night mode for GUI

### 📚 How to use
Install Pygame:
```
pip install pygame
```
And then run the script:

```
python3 euclid_2d.py
```
