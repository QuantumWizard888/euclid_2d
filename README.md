# Euclid 2D

## ⚛️ Simple particles simulation sandbox
<video width="640" height="360" controls>
  <source src="demo.mp4" type="video/mp4">
</video>

Small particles simulation with physics. Created using Pygame.

### ⭐ Feautures
* Multiple particles creation with collision physics
* Gravity mode
* Single particle that contols by a mouse and can be used as a "hammer" for other particles
* Pause simulation

### 📚 How to use

Just run the script:

```
python3 euclid_2d.py
```
